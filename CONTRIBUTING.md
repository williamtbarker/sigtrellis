# Contributing

Install `.[dev,de,demo]` and run the verification commands in README. Keep input adapters separate from sample-level modeling. A change to preprocessing, selection, splitting, tuning or claims must include an adversarial scientific test, not only a software happy-path test. Never loosen leakage/grouping checks to make an example complete. Explain changes to the estimand and update RESEARCH, LIMITATIONS and CHANGELOG when assumptions change.

Do not submit private patient data, proprietary employer code, access credentials, or large datasets. Public data fixtures need stable provenance, checksums and explicit reuse terms. Reports may contain sample identifiers; review before sharing.
