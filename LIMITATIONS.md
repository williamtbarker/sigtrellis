# Limitations and interpretation contract

This is general-purpose research software, not a clinically validated system. It can analyze new organisms/cell lines under the input and replication contract; no statistical method can guarantee a biomarker from every arbitrary dataset. Production-oriented packaging does not make the methodology universally correct.

The 0.1.1 review adds artifact integrity checks, exact identifier handling, stricter paired-DE replication contracts and contrast-specific correlation evidence. Artifact hashes detect changes relative to a trusted manifest; they do not authenticate a manifest that has also been altered. Paired DE supports one observation per donor/condition, not arbitrary repeated visits.

1. **Association only.** Neither selection, stability, count-DE support nor strong cross-validation establishes biological validation, a mechanism, causality, clinical utility or qualification. An external assay, independent cohort, and an appropriate intended-use study are separate requirements.
2. **Performance scope.** Nested CV evaluates a training procedure on smaller training sets. Optional compact-panel CV includes selection inside outer training folds and has separate metrics. The final fixed full model/panel still needs untouched evaluation. A compact predictor set is not a validated small assay: count normalization retains the original full gene universe. Confidence intervals are not inferred from overlapping folds.
3. **Small studies.** No universal minimum donor count guarantees trustworthy modeling. The default 20-group gate is conservative operational policy, not a power calculation. The small airway/Kang examples fail it; larger examples do not eliminate other limitations. Within-group permutations can have very few unique labelings even when many Monte Carlo draws are requested. The inexpensive demonstration grids/resample counts are not default recommendations for a definitive study.
4. **Empirical stability.** Overlapping retuned subsamples do not meet all assumptions needed for formal PFER control. Frequencies are not posterior probabilities or p-values. Perturbation-specific frequencies and group stability are descriptive; larger groups mechanically have more chances to be selected.
5. **Confounding.** Perfect batch/phenotype confounding is not computationally resolvable. Purged batch evaluation can become impossible when donors span all batches. Missing batch metadata does not establish robustness. PCA and contingency diagnostics cannot detect every nuisance factor.
6. **Covariates.** Predictive covariates are penalized jointly with genes. No unpenalized logistic nuisance solver or conditional permutation test is provided. When covariates are used, positive robustness gates are withheld because the global permutation test is not a conditional gene test.
7. **DE scope.** PyDESeq2 supports binary, continuous and reference-class multiclass contrasts with fixed nuisance terms. It is not a general mixed model. Rank-deficient and saturated designs are rejected. Paired fixed effects do not estimate a donor-constant phenotype. Supporting DE is same-cohort evidence; p-values after arbitrary upstream selection may not have nominal interpretation. Continuous effects are per original outcome unit, not per standardized predictor unit. Unshrunk fold changes can be noisy. Distribution-mode supporting DE tests gene count means, not abundance or variance.
8. **Normalization.** LogCPM and median-ratio transformations assume a meaningful declared gene universe. Relative/compositional shifts can mimic gene changes; strong global RNA-content changes need spike-ins or an appropriate design. Frozen median-ratio fitting can fail in highly sparse training data. TPM/log/integrated matrices cannot be interpreted as raw counts.
9. **Input provenance.** Hidden phenotype encodings, globally selected genes, outcome-assisted embeddings, annotation leakage, externally imputed/scaled matrices, near-duplicate or relabeled specimens, and undisclosed relationships cannot all be detected. Exact target copies and exact duplicated profiles catch specific mistakes, not all leakage. You must supply correct group identities.
10. **Single-cell assumptions.** Pseudobulk targets sample-level expression within supplied cell types. Distribution mode separately preserves abundance, detection, observed variability and fixed program distributions. Abundance is compositional recovery; variability includes technical noise. These are predictive features, not formal differential-abundance/variance inference or cell-level response probabilities. Program definitions are equal-weight summaries, not validated pathway scores. Doublets, ambient RNA and annotation errors remain upstream. Annotations can have been influenced by condition/integration. Fixed QC changes the target population. Missingness can encode recovery bias. Donor/culture counts remain the sample-size constraint.
11. **Multiple comparisons.** Operational feature gates are not gene-level error control. Binary/continuous DE uses backend BH within that analysis; multiclass corrects genes × reference contrasts; multiple distribution-state DE results share one family. The CLI adjusts global permutation eligibility across multiple requested pseudobulk types. Trying many representations/outcomes/configurations still needs prespecified multiplicity handling and independent validation. The two larger single-cell demonstrations are prespecified software comparisons, not a winner-selection claim.
12. **Exchangeability.** Group and within-group permutations must follow the design. Time trends, treatment order, differential sampling and covariate structure can invalidate inference. Forward temporal CV is supported but unrestricted temporal permutations remain labeled unverified and cannot produce positive gates. Censored outcomes/survival are not supported. Stratifying by batch cannot remove every observational confounder.
13. **Scale and runtime.** Chunked H5AD aggregation avoids a dense cells-by-genes matrix. The sample-level accumulator and models remain dense. Running all cell types can increase memory substantially. Large nested DE/permutation experiments are expensive; no performance promise is made for atlas-scale studies.
14. **Portability.** Seeds, source hashes, versions and thread limits are recorded. Bitwise identity across CPU/BLAS/library versions is not guaranteed. Prepared HDF5/gzip byte streams may vary even when biological counts are identical. A clean Python 3.12 installation is verified; CI definitions for additional Python versions are supplied but are not a report of executed remote CI.
15. **Distinct research extensions.** No automatic pathway enrichment, learned/deconvolved program scores, survival analysis, interactions, cell-level mixed models, donor random effects, Milo/scCODA/Memento backend, neural multiple-instance classifier, nested probability recalibration, frozen batch harmonization, or conditional feature-level significance. These are distinct methods and research targets, not alternate names for implemented summaries. External evaluation currently requires at least four groups and the configured outcome family; extremely small or single-class external cohorts need separately defined descriptive evaluation.
